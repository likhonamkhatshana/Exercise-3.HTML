# Interactive Product Showcases
I have created an interactive product showcase website using HTML and CSS animations.
## Features
- Animated navigation menu
- Product hover effects
-  Loading spinner animattion
- Responsive design
- Hero section with animated background
## Technologies used
- HTML
- CSS
- VS Code
## How to run
1. Download the project files
2. Open the folder in VS Code
3. open 'products.html' in your browser
## Project Structure
1.products.html
2.style.css
3.README.md
